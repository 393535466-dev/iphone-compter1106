# 开发验收记录 · 2026-11-06

## 保留、修改、核查

保留 CmdPalm 触控板、键盘、Deck、设备配对与重连、本机 Apple 识别。新增功能放在独立“助手”入口，不迁移旧 Node 项目的任务与网关代码。

修改了以下明确问题：

- 指定应用“调出来”使用 open，避免 toggle 将正在显示的应用隐藏。
- “下载文件夹”有独立 folder 动作，不能以“只打开访达”冒充完成。
- 输入正文逐字保留，修复英文命令前缀混入正文。
- 原版动作超时曾被当成成功；现在明确提示未确认。
- 执行与结果核验分开，文字按本次插入前后的完整内容核查，无法核实就标明。
- 音频由原先 100 毫秒帧缩至 20 毫秒，并确认末尾残帧；末帧失败、断线、取消、后台切换或麦克风被占用后不自动执行残缺指令。
- 云端语音保留现有实时传输，不再使用录完上传整段文件的流程；增加最多一个、20 秒过期的无音频预热连接。
- Key 只保存在 Mac，原版“任何数据都不出网”的文案已按新增云服务能力修正。

## 意图规划比较

同一个 Swift 产品规划器、同一份提示词与动作校验。每个模型一个持续运行的进程。第一条真实模型请求作为冷连接，不计入表中中位数；本地规则也不计入模型耗时。P95 使用 nearest-rank。错误请求单列，未混入成功请求的耗时统计。

| 模型 | 30 条回归集 | 15 条新增表达 | 回归模型 P50 / P95 | 新增表达模型 P50 / P95 |
| --- | --- | --- | --- | --- |
| deepseek-flash | 30/30 | 15/15 | 1.431 / 1.689 秒 | 1.338 / 1.550 秒 |
| qwen3.7-flash | 29/30 | 15/15 | 1.636 / 2.166 秒 | 1.582 / 2.139 秒 |
| qwen-flash | 29/30 | 14/15 | 1.100 / 1.655 秒 | 0.967 / 1.417 秒 |

回归集中有 6 条由本地规则完成；新增 15 条全部调用模型。测试有明确能力边界，包含闲聊不操作、对象不明补问、拒绝删除与发消息等情形，计分是规划与校验合同，**不是桌面实际操作成功率**。模型结果每次可能变化，45 条小样本不能保证通用准确率。

Qwen3.7 一条搜索计划多开了空白标签页。早期最短计划评分将其判错；最终语义评分接受这一步，未将无害的多一步当作理解失败。它仍有一条将“向微信当前输入框输入且不发送”误判为不支持。Qwen Flash 有两条结果未通过结构校验，程序均未执行。

结论：这个阶段保留 DeepSeek 作为默认；现有 Key 足以承担已测的基本意图，不需要先换更贵模型。Qwen3.7 可作为后续备用候选；Qwen Flash 更快更便宜，但本轮可靠性较低。不存在已启用的静默跨服务商重试。

原始合成记录见 [evaluation/summary.json](evaluation/summary.json) 以及同目录每个模型的结果。没有保存用户聊天内容或界面截图到模型评测中。

## 语音链路

使用人工合成音频，经同一 Swift AliyunSpeechService 实时发送 16 kHz PCM，没有调用桌面执行，也没有采集现场麦克风。

- “你好”完整识别为“你好。”。
- 约 10.7 秒的完整英文保留了 README、npm test、GitHub Actions workflow 等全部英文词。
- 中英混说保留 Google Chrome、how to configure a GitHub Actions workflow 和中文部分；有大小写及标点规范化。
- 未预热短语音连接准备约 1.9～3.7 秒，是明确的冷连接瓶颈。
- 按所选语言预热后，三次“你好”的结束到完整结果分别约 0.430、0.430、0.402 秒。
- 预热测试先等待 3 秒再送音频；这些等待没有隐藏成“零耗时”。原始 firstTextMs 包含预热期，finishMs 才是结束录音后的等待。

这些结果**不代表 iPhone 麦克风、蜂窝网络或用户真人口音已验收**。音频末尾与停顿处理的浏览器回归已覆盖，真人语音还需手机实测。原始结果见 [evaluation/asr.json](evaluation/asr.json)。

## 成本口径

截至本次核验，北京区 Qwen ASR Realtime 按输入音频时长约 **0.0198 元/分钟**；例如每天录 30 分钟、30 天约 17.82 元，仅包含识别费用。预热不上传音频，不以全天录音维持连接。[阿里云官方价格](https://help.aliyun.com/zh/model-studio/model-pricing)

以回归样本实际平均用量、无缓存折扣估算，每 1,000 次模型调用：DeepSeek 高峰约 **0.28 美元**，Qwen3.7 Flash 约 **0.22 元**，Qwen Flash 约 **0.18 元**。DeepSeek 非高峰为一半；缓存命中通常更低。模型失败也可能收费；少数被校验拒绝的结果未保留用量，所以没有把本次总账单伪装成精确结算。

此估算使用 5 个合成应用名称的短上下文，真实 Mac 应用列表更长时会增加输入用量。明确短指令本地完成，不产生 LLM 调用费用。两家货币单位不同，未使用未经核验的汇率。[DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)，[阿里云官方价格](https://help.aliyun.com/zh/model-studio/model-pricing)
